# War Nexus Artist Brief Template

Use this template when handing work to an artist or external art team.

## Project

`War Nexus`

Mobile online military strategy game.

## Screen

`Base Screen`

Portrait mobile layout.

## Goal

We need believable, premium-looking military base assets for a mobile strategy game.

The art should feel:

- grounded
- modern
- tactical
- dense
- readable on mobile

## Camera

High 2.5D tactical angle.

Not side view.
Not fully top-down.

## Style

- realistic-stylized
- premium mobile strategy
- stronger than placeholder art
- not cartoonish
- not browser clutter

## Color Direction

- warm sand and concrete for terrain
- muted industrial browns
- steel and dust tones
- limited cyan for tech accents only

## Key Buildings

### HQ

Needs:

- strong central mass
- visible command identity
- helipad logic
- secure entry
- clear upgrade prestige

### Oil Refinery

Needs:

- industrial weight
- tank silhouettes
- pipe logic
- service/loading feel

### Barracks

Needs:

- troop housing identity
- camp/training feel
- more permanent military structure in higher tiers

## Tier Logic

Each building requires:

- Tier 1: early / modest
- Tier 2: stronger / established
- Tier 3: prestigious / advanced

Tier increases must be obvious in:

- silhouette
- footprint
- detail density
- prestige

## Technical Output

- transparent PNG
- large source resolution
- clean silhouette
- no baked-in labels or tiny text

## Deliverable Naming

Use exact names from the project registry:

- `hq_t1.png`
- `hq_t2.png`
- `hq_t3.png`
- `oil_refinery_t1.png`
- `oil_refinery_t2.png`
- `oil_refinery_t3.png`
- `barracks_t1.png`
- `barracks_t2.png`
- `barracks_t3.png`

## Quality Rules

- must read clearly on phone screen
- must not look toy-like
- must fit a shared scene perspective
- must feel more polished than current prototype
