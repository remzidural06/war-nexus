- sınırlı ve kontrollü medikal vurgu kullanılmalı
- parlak sivil beyaz + kırmızı hastane diline kaçmamalı
- Tier 1 daha sahra tipi, Tier 2 daha oturmuş klinik, Tier 3 daha prestijli ileri tedavi merkezi gibi görünmeli

## English

### Project

`War Nexus`

A mobile online military strategy game.

### Target Screen

`Base Screen`

Portrait mobile layout.
This is the player’s main home base screen.

### Desired Visual Direction

- modern military base
- premium mobile strategy feel
- grounded but stylized
- strong silhouettes
- readable detail level on mobile

Reference feeling:

- powerful command center
- living base compound
- clear separation between industrial, military, and tech zones

### What We Do Not Want

- cartoon feel
- toy-like assets
- tiny unreadable detail
- cluttered browser-game look
- flat pastel blocks

### Camera

- high-angle 2.5D
- not fully isometric
- top-down command view feeling
- all assets must share the same perspective

### Priority Assets

1. `HQ`
2. `Oil Refinery`
3. `Barracks`
4. `Research Lab`
5. `Power Plant`
6. `Ammo Factory`
7. `Hospital`

### Final Building Scope

For this project, the building roster is locked to these 7 structures.

- `HQ`
- `Oil Refinery`
- `Barracks`
- `Research Lab`
- `Power Plant`
- `Ammo Factory`
- `Hospital`

Notes:

- no additional building types will be planned beyond this list
- economy, upgrade loops, combat balance, and visual production should be designed around this fixed building set
- future work should focus on polishing, balancing, and deepening the gameplay of these 7 buildings instead of adding new ones

### Tier Logic

Each building needs 3 stages:

- `Tier 1`: early / modest / basic
- `Tier 2`: established / upgraded / stronger
- `Tier 3`: prestigious / advanced / impressive

Tier growth must be visible through:

- silhouette
- footprint feel
- detail density
- prestige

### Building Notes

#### HQ

- must be the visual anchor of the base
- should include helipad logic
- should feel secure and important
- must look like the most expensive structure

#### Oil Refinery

- should feel like heavy industry
- tanks, stacks, and pipe logic must read clearly
- should include service/loading logic

#### Barracks

- should communicate troop housing and training
- lower tiers can feel more like a camp
- higher tiers should feel more like a permanent garrison

#### Research Lab

- should feel clean and technical
- limited cyan accents are acceptable
- should not drift into extreme sci-fi

#### Power Plant

- should feel functional
- generators, pylons, reservoirs, and transformers are welcome

#### Ammo Factory

- should feel dangerous and industrial
- bunker language, ammo racks, blast doors, and loading bays are useful

#### Hospital

- should read as a forward military medical facility, not a civilian hospital
- should feel clean, controlled, and dependable
- should not feel as futuristic as the Research Lab
- should not feel as temporary or camp-like as the Barracks
- a low-rise but horizontally spread silhouette is preferred
- triage zone, protected emergency entry, medical module, or field tent extension can help readability
- medical accents should be limited and disciplined
- avoid bright civilian white-red hospital language
- Tier 1 can feel more field-based, Tier 2 more established, Tier 3 more like a prestigious advanced treatment center

### Terrain Notes

We also need separate ground/environment layers for:

- main base terrain
- runway
- roads
- command plaza
- industrial ground
- military camp ground
- coast edge / world edge

### Technical Output

- transparent PNG
- high-resolution source art
- must remain readable when scaled down for mobile
- no text baked into the asset
